# Expense Tracker

A responsive expense tracking web application built with React and Vite. The application allows users to record, manage, and monitor their income and expenses through a simple and user-friendly interface.

## Features

- Add and manage expenses
- Track income and spending
- Categorize transactions
- View total income, expenses, and balance
- Responsive user interface
- Dynamic expense data
- Clean and modern dashboard
- Fast development with Vite

## Technologies Used

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- ESLint
